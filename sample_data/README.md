# Sample Data

Place **synthetic/demo** document images here for testing.

## What to put here

| File | Description |
|------|-------------|
| `sample_passport.jpg` | A clearly fake/demo passport image |
| `sample_visa.jpg` | A clearly fake/demo visa image |
| `sample_person.jpg` | A headshot photo matching the passport face |

## ⚠️ IMPORTANT

- **Do NOT upload real government documents here.**
- Use publicly available sample passport templates or AI-generated synthetic documents.
- Mark any demo images clearly as "SPECIMEN" or "NOT VALID".
- This data is for hackathon demonstration purposes only.

## Sources for demo/synthetic images

- [Thispersondoesnotexist.com](https://thispersondoesnotexist.com) — AI-generated faces
- Online "SPECIMEN" passport templates (for the document layout)
- Create your own with any image editor

## .gitignore note

Real document images should be added to `.gitignore` to avoid accidental uploads.
